# Fast Files icons

Generated with the built-in image generation tool. Paperstream is the default app icon; Tailwind and Slipstream are alternative proposals. PNG masters retain transparent backgrounds.

Run `bun run build:icon` to regenerate the macOS `icon.iconset` from Paperstream. The packaging command consumes that icon set to create the app's `.icns` resource. No image-processing package is required; the script uses macOS `sips`.

## Generation prompts

### tailwind

Use case: stylized-concept. Create one finished 1024×1024 macOS application icon for Fast Files, a very fast file archive viewer. Concept: a golden yellow file folder swept forward by an elegant ivory gust of wind. The gust is three bold smooth flowing strokes crossing the lower foreground, with one beautifully curled tip; visually integrated with the folder rather than a separate emoji. Distinctive simple silhouette, slightly playful premium desktop software design. The folder is a gently dimensional sculpted object with a subtle folded tab, warm amber shading, crisp soft edges, almost front-facing, small upward tilt. Place on a dark deep teal rounded-square macOS icon tile, luminous soft light from upper left, restrained depth. Strong warm/cool contrast, reads clearly at 32px. Tile occupies about 82% of square canvas, centered, generous consistent transparent outer margins, soft short shadow. Transparent pixels outside rounded tile, no white backdrop. Only one icon, no mockup, no words, no letters, no badge, no watermark.

### paperstream

Use case: stylized-concept. Create one finished 1024×1024 macOS application icon for a fast file viewer. Concept: Paperstream — a soft pale cream file folder with two little sheets inside, and a single rich blue sculpted wind ribbon curling smoothly around its lower half and streaming to the right, like a breeze riffling through an archive. Modern tactile clay-like 3D desktop app icon, polished but not glossy, simplified large shapes, friendly refined personality, lovely folded-folder silhouette. Pale periwinkle rounded-square macOS tile behind the folder, soft upper-left studio lighting and subtle contact shadows. Readable at 32 pixels; no fussy detail. One centered icon tile occupies about 82% of canvas, generous transparent outer margins on all sides. Actual transparency outside rounded tile, not a white background. No words, no letters, no additional symbols, no mockup, no watermark.

### slipstream

Use case: logo-brand. Create one finished 1024×1024 macOS application icon for a very fast file viewer. Concept: Slipstream — a bold vivid cobalt file folder leaning forward, with three broad mint-white wind trails that sweep from its left edge into a single clean curl across the folder face, expressing speed and browsing through files. Make a beautiful graphic silhouette, extremely simple geometric shapes, clean 2.5D layered paper construction with restrained highlights and shadows, sophisticated indie Mac utility. Put it on an inky navy rounded-square macOS app tile. Strong contrast, excellent legibility when reduced to 32px. The centered rounded tile occupies about 82% of the square image, leaving evenly generous transparent margins; a small soft shadow below. Only one finished app icon. Actual transparency outside the tile. No words, no letters, no numbers, no extra badges, no background scene, no watermark.
